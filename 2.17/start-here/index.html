    Learning paths¶

    NKP brings together Kubernetes, cloud native operations, infrastructure, and AI workloads. You do not need to master every component before using the platform, but shared terminology and mental models make cross-team design easier.

    These optional paths are organized by topic and role. Experienced readers can skip directly to Architecture, Installation, or Upgrades.

    • System engineer

      Start with the differences between virtual machines and Kubernetes, then learn the cloud native operating model.

      From VMs to Kubernetes

    • Kubernetes or platform engineer

      Review the NKP-specific concepts, then continue into architecture and installation.

      NKP in 10 minutes

    • Sales engineer or architect

      Learn what NKP manages, why cloud native operations differ, and where Nutanix infrastructure adds value.

      Cloud native for system engineers

    • AI platform engineer

      Understand models, runtimes, GPUs, gateways, storage, and the role of Kubernetes in inference.

      AI inference fundamentals
